# Шпаргалка по клавишам: Neovim и Yazi

`<leader>` = `Space`. `<localleader>` = `\`.

---

## Neovim

### Базовое

| Клавиши                  | Действие                               |
| ------------------------ | -------------------------------------- |
| `jk` (в Insert)          | выйти в Normal                         |
| `<C-h/j/k/l>`            | перейти в окно влево/вниз/вверх/вправо |
| `<A-Left>` / `<A-Right>` | предыдущий/следующий буфер             |
| `<leader>t`              | новая вкладка                          |
| `<leader>e`              | открыть/закрыть Neo-tree               |
| `<Esc>` (в терминале)    | выйти в Normal                         |
| `x` + `p`                | вставить, не затирая регистр           |

### Файлы и поиск (Telescope)

| Клавиши      | Действие                   |
| ------------ | -------------------------- |
| `<leader>fn` | найти файл                 |
| `<leader>fg` | grep по проекту            |
| `<leader>fb` | буферы                     |
| `<leader>fo` | недавние файлы             |
| `<leader>fd` | диагностика                |
| `<leader>fh` | help                       |
| `<leader>fm` | LSP references             |
| `gR`         | LSP references (Telescope) |

### Yazi из Neovim

| Клавиши      | Действие                           |
| ------------ | ---------------------------------- |
| `<leader>-`  | открыть Yazi в текущем файле/папке |
| `<leader>cw` | открыть Yazi в cwd                 |
| `<C-Up>`     | вернуться в последнюю сессию Yazi  |

### LSP

| Клавиши      | Действие                         |
| ------------ | -------------------------------- |
| `gd`         | определение                      |
| `gD`         | объявление                       |
| `gi`         | реализации                       |
| `gT`         | определение в новой вкладке      |
| `K`          | документация под курсором        |
| `[d` / `]d`  | предыдущая/следующая диагностика |
| `<leader>ln` | диагностика текущей строки       |
| `<leader>lm` | диагностика буфера               |
| `<leader>rs` | перезапустить LSP                |

### Форматирование, git, диагностика

| Клавиши                     | Действие                           |
| --------------------------- | ---------------------------------- |
| `<leader>fr`                | форматировать буфер (conform)      |
| `<leader>xx` / `<leader>xX` | Trouble: все ошибки / только буфер |
| `]h` / `[h`                 | следующий/предыдущий git-хук       |
| `<leader>hs` / `<leader>hr` | stage/reset хунка                  |
| `<leader>hp` / `<leader>hb` | preview хунка / blame строки       |
| `<leader>u`                 | дерево undo                        |

### Редактирование

| Клавиши                   | Действие                                                |
| ------------------------- | ------------------------------------------------------- |
| `gcc` / `gbc`             | закомментировать строку / блок                          |
| `gc` (visual)             | закомментировать выделенное                             |
| `sa` / `sd` / `sr`        | добавить / удалить / заменить окружение (mini.surround) |
| `sf` / `sF` / `sh`        | найти окружение вперёд / назад / подсветить             |
| `<leader>m`               | treesj: toggle split/join                               |
| `<leader>j` / `<leader>s` | treesj: join / split                                    |
| `a` / `i`                 | mini.ai: вокруг / внутри текстового объекта             |
| `<Tab>` / `<S-Tab>`       | tabout из скобок/кавычек                                |

### Flash

| Клавиши               | Действие             |
| --------------------- | -------------------- |
| `zx`                  | прыжок по экрану     |
| `Zx`                  | прыжок по treesitter |
| `r` (operator)        | remote Flash         |
| `R` (operator/visual) | treesitter search    |
| `<C-s>` (cmdline)     | toggle Flash         |

### Completion (nvim-cmp)

| Клавиши           | Действие                |
| ----------------- | ----------------------- |
| `<C-Space>`       | вызвать completion      |
| `<C-e>`           | отменить                |
| `<CR>`            | подтвердить             |
| `<C-b>` / `<C-f>` | прокрутить документацию |

### Сессии

| Клавиши      | Действие                       |
| ------------ | ------------------------------ |
| `<leader>qs` | загрузить сессию текущей папки |
| `<leader>qS` | выбрать сессию                 |
| `<leader>ql` | загрузить последнюю сессию     |

### Запуск кода

| Клавиши     | Действие                                                 |
| ----------- | -------------------------------------------------------- |
| `<leader>r` | запустить: Python / C++ / C# (в зависимости от filetype) |

## Yazi

### Открытие и выбор

| Клавиши           | Действие                              |
| ----------------- | ------------------------------------- |
| `Enter` или `l`   | папка → войти; файл → открыть/выбрать |
| `o`               | открыть                               |
| `O` / `<S-Enter>` | открыть с выбором приложения          |
| `q`               | выйти                                 |
| `Q`               | выйти без записи cwd                  |
| `<C-c>`           | закрыть вкладку                       |
| `<C-z>`           | приостановить Yazi                    |

### Навигация

| Клавиши           | Действие                  |
| ----------------- | ------------------------- |
| `j` / `k`         | вниз / вверх              |
| `h` / `l`         | к родителю / войти        |
| `H` / `L`         | назад / вперёд по истории |
| `gg` / `G`        | в начало / в конец        |
| `<C-u>` / `<C-d>` | полстраницы вверх / вниз  |
| `<C-b>` / `<C-f>` | страница вверх / вниз     |
| `K` / `J`         | прокрутить preview        |
| `Tab`             | информация о файле        |

### Выделение и операции

| Клавиши           | Действие                       |
| ----------------- | ------------------------------ |
| `Space`           | выделить и перейти вниз        |
| `<C-a>` / `<C-r>` | выделить всё / инвертировать   |
| `v` / `V`         | visual-режим                   |
| `y` / `x`         | копировать / вырезать          |
| `p` / `P`         | вставить / вставить с заменой  |
| `d` / `D`         | в корзину / удалить навсегда   |
| `a` / `A`         | создать файл / массово создать |
| `r`               | переименовать                  |
| `-` / `_`         | симлинк (абс./относ.)          |
| `<C-->`           | хардлинк                       |

### Поиск и переходы

| Клавиши     | Действие                                  |
| ----------- | ----------------------------------------- |
| `/` / `?`   | поиск вперёд / назад                      |
| `n` / `N`   | следующий / предыдущий результат          |
| `f`         | фильтр                                    |
| `s` / `S`   | поиск по имени (fd) / по содержимому (rg) |
| `z` / `Z`   | fzf / zoxide                              |
| `g h`       | домой                                     |
| `g c`       | `~/.config`                               |
| `g d`       | `~/Downloads`                             |
| `g p`       | `~/Projects`                              |
| `g l`       | `~/Projects/Labs`                         |
| `g <Space>` | перейти интерактивно                      |
| `g f`       | перейти по симлинку                       |

### Вкладки

| Клавиши   | Действие                       |
| --------- | ------------------------------ |
| `t`       | новая вкладка в текущей папке  |
| `1`…`9`   | перейти на вкладку             |
| `[` / `]` | предыдущая / следующая вкладка |
| `{` / `}` | поменять вкладки местами       |

Примечание: из-за прямого бинда `t` дефолтные `t t` / `t r` перекрыты.

### Сортировка и linemode

| Клавиши         | Действие                                         |
| --------------- | ------------------------------------------------ |
| `,m` / `,M`     | сортировка по mtime                              |
| `,b` / `,B`     | по btime                                         |
| `,e` / `,E`     | по расширению                                    |
| `,a` / `,A`     | по алфавиту                                      |
| `,n` / `,N`     | natural                                          |
| `,s` / `,S`     | по размеру                                       |
| `,r`            | случайно                                         |
| `m s/p/b/m/o/n` | размер / права / btime / mtime / владелец / выкл |

### Плагины и наши бинды

| Клавиши       | Действие                       |

### Прочее

| Клавиши        | Действие                      |

## tmux

Префикс — `C-b`. Открыть tmux: `~/.config/tmux/attach` (сессия `main`, с восстановлением). Выйти: `C-b d`.

### Окна

| Клавиши                  | Действие                        |
| ------------------------ | ------------------------------- |
| `C-b c`                  | новое окно в текущей папке      |
| `Alt+1` … `Alt+9`        | перейти на окно 1…9             |
| `C-b n` / `C-b p`        | следующее / предыдущее окно     |
| `C-b L`                  | последнее окно                  |
| `C-b ,`                  | переименовать окно              |
| `C-b &`                  | закрыть окно                    |
| `C-b <` / `C-b >`        | сдвинуть окно влево / вправо    |

### Панели

| Клавиши                     | Действие                              |
| --------------------------- | ------------------------------------- |
| `Alt+h/j/k/l`               | панель влево / вниз / вверх / вправо  |
| `Alt+Shift+h/j/k/l`         | изменить размер панели                |
| `C-b h/j/k/l`               | то же через префикс                   |
| `C-b \|` / `C-b -`          | сплит вправо / вниз                   |
| `C-b x`                     | закрыть панель                        |
| `C-b z`                     | zoom панели                           |
| `C-b S`                     | синхронизировать ввод во все панели   |
| `C-b {` / `C-b }`           | поменять панели местами               |

### Копирование

| Клавиши                     | Действие                              |
| --------------------------- | ------------------------------------- |
| `C-b [`                     | copy mode (vi)                        |
| `v` / `V`                   | выделение / целая строка              |
| `C-v`                       | прямоугольное выделение               |
| `y` / `Enter`               | скопировать в Wayland-буфер (`wl-copy`) |
| `q` / `Esc`                 | выйти из copy mode                    |
| `C-b ]`                     | вставить буфер tmux                   |
| `C-b =`                     | список буферов                        |

### Сессии, конфиг, плагины

| Клавиши                     | Действие                              |
| --------------------------- | ------------------------------------- |
| `C-b d`                     | detach, сессия продолжает работать    |
| `C-b $`                     | переименовать сессию                  |
| `C-b s`                     | список сессий                         |
| `C-b r`                     | перезагрузить конфиг                  |
| `C-b C-s`                   | сохранить сессию (resurrect)          |
| `C-b C-r`                   | восстановить сессию                   |
| `C-b I`                     | установить плагины (TPM)              |
| `C-b U`                     | обновить плагины (TPM)                |
| `C-b Alt+u`                 | удалить неиспользуемые плагины (TPM)  |

- Мышь включена: клик переключает панель, колесо входит в copy mode.
- Kitty открывается как обычный терминал; `Alt+hjkl`, `Alt+1..9` и `C-b` в нём не заняты. Создание вкладок и сплитов kitty отключено (`ctrl+shift+t`, `ctrl+shift+enter`).

## Заметки

- В Neovim номера строк: `number` + `relativenumber`; git-значки `gitsigns` отключены (`signcolumn = false`).
- В Yazi используются дефолтные бинды 26.9.1 + наши `prepend_keymap`.
- Плагины Yazi: smart-enter, full-border, git, chmod, diff, mime-ext, toggle-pane, restore, ouch.
- `fzf` и `zoxide` — встроены в Yazi 26, отдельно ставить не нужно.
